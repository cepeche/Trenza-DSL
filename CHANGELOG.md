# Changelog

All notable changes to the Trenza DSL project will be documented in this file.

## [v0.0.1] - 2026-03-20

### Changed
- Comprehensive rename from Helix to Trenza across the entire specification
  and tooling.
- Repository restructured separating `spec/`, `history/` and `docs/` to
  preserve the probative history of the co-design process ("Lab Notebook").
- `.helix` files renamed to `.trz`.
- Reserved keyword `bloqueado` replaced by `forbidden`.
- License changed to Dual: AGPL-3.0 with a commercial option for AI Model
  providers.

### Historical note
The state prior to the rename and the prototype organisation (flat `docs/`
and `examples/`) is preserved in full in the git tag `v0.0.0`.
